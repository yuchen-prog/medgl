## 1. 操作与语义

侧栏 Crop 页签的 `Crop volume` 提供开关、三组起止百分比和 `Reset crop` 图标，关闭时隐藏范围控件。每组表示保留区间，默认0%至100%；UI以1%调整并至少保留1%的跨度，起止不会互相跨越。切换页签不重置参数，裁切启用时页签保留状态点。

| 轴 | 依据 | 不应理解为 |
| --- | --- | --- |
| Columns (X) | 解码体的列索引轴 |
| Rows (Y) | 解码体的行索引轴 |
| Slices (Z) | 按几何排序后的层索引轴 |

这些数据轴经过DICOM方向矩阵映射到患者空间，斜扫描下不一定与LPS三个轴重合，也不随相机转成屏幕横/纵/深度。患者方向仍以画布L/R、A/P、S/I标签为准。

调节时使用原有节流预览与停止后的精细帧；关闭开关保留所选范围但渲染完整体，再开启恢复该范围。Reset恢复关闭状态与完整范围，不重置相机、颜色表、窗宽窗位或背景。预设、标准视角和重连保留裁剪；重新加载序列则恢复默认，避免沿用另一个体的裁剪状态。

画布 `CROPPED` 标记来自已显示图像的裁剪快照，参数改动尚未出图时不抢先更新。下载PNG对应当前完成的精细seq/revision，包含裁剪效果。旧服务未声明裁剪能力时控件禁用，旧请求或旧帧省略字段仍可使用完整体。

## 2. CUDA实现

`CropBox` 使用各轴归一化minimum/maximum，必须有限且满足 `0 <= minimum < maximum <= 1`，即使关闭状态也验证范围。原始体边界为 `[-0.5, N-0.5]`，归一化值c映射为：

$$
v_{boundary} = cN - 0.5
$$

因此0/1保持原边界，0.5处于覆盖长度的中点，不是直接取某个切片中心。射线在患者空间生成并变换到体素空间，slab求交改为这组裁剪边界；采样只沿保留的相交区间进行。参数仍以物理mm度量，最后小于步长的区段按实际长度校正alpha。

不修改CPU体、CUDA体纹理或DICOM；裁剪开关不会重新加载体。关闭与完整范围保持原求交边界和像素。没有给截面生成额外封口面、材质或分割标签，仍使用原强度/TF积分。边缘的三线性插值和光照梯度使用原纹理邻居，可能访问裁剪区外相邻体素，不等于将纹理裁成另一份数据。

## 3. 协议

render消息新增可选绝对状态，与camera/style一同参与latest-wins，不能使用增量裁剪指令：

```json
{
  "cropBox": {
    "enabled": true,
    "minimum": [0.5, 0, 0],
    "maximum": [1, 1, 1]
  }
}
```

这只是现有render对象的一段，其他必需字段不变。ready会话声明 `cropBoxSupported=true`，`initial.cropBox` 返回默认状态，图像元信息附实际 `cropBox`。不改变protocolVersion=1、seq或sceneRevision语义。后端范围检查在JSON边界和renderer分别执行，错误不能进入kernel。

## 4. 已验证

- 实际GPU常量体，置换轴/患者原点与各向异性spacing：关闭及全范围逐像素一致，半深度和内部区间opacity符合解析物理长度。
- 正/反向相机、平行射线排除后背景、不同步长以及小于步长的薄区间；开启均匀体光照仍正确。
- 非有限、越界、逆序、零跨度拒绝；服务拒绝缺字段、错误类型/数组长度，旧请求默认关闭。
- 前端解析与状态：旧帧兼容、旧服务不发送裁剪、输入拷贝、预设/视角/重连保留、加载新序列重置。
- 合成CT真实浏览器：图像裁剪变化，关闭后Canvas逐像素恢复，帧裁剪快照正确，PNG签名/尺寸、预设/视角保留与重置通过。
- 320/390px侧栏控件无横向溢出，默认和fast PNG模式各5项真实后端测试通过。

本次完整构建/回归为原生12/12、前端单元67项、模拟浏览器5项、实际浏览器5项。截图只使用合成体，保存在忽略的 `web/test-results-real/crop-*.png`。

授权真实CT在当前8081查看器复验：512×512×999、输出1104×783，列轴保留50%至100%时201,725个Canvas通道字节相对完整体发生变化；Reset后与原画布逐字节比较错配0，关闭并恢复全范围。比较缓冲只在浏览器临时内存中使用并已清除，没有保存患者图像，也不把该变化计数当作医学正确性或性能指标。

**图片占位：合成CT裁剪前后及窄屏控制。** 不嵌入授权患者图像；实际图像变化不代表医学定量或临床正确性。

## 5. 边界与后续

第一版只提供数据轴对齐裁剪盒，不提供自由平面、鼠标拖动3D手柄、封口面或自动器官提取。切掉体素后从透明度/插值获得的截面不是MPR切片，不能用作HU测量。

根据本轮任务调整，长时间压力、OOM恢复和异机交付暂搁置；现有运行ZIP保留上一阶段内容，不随本次功能重打。当前裁剪需从更新后的源码构建运行。后续功能可在这套范围状态上扩展自由切平面或局部取景，不默认拓展至MPR。
