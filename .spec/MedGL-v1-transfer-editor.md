## 1. 编辑与显示

Display 页签的 `Transfer preset` 选择内置预设时，加载服务端给出的完整 RGBA 控制点。内置八套预设不被修改；当前编辑只是一个视图样式快照。

左侧三个页签分别使用 Lucide 的 `SlidersHorizontal`（Display）、`Crop`（Crop）、`Info`（Info），保留文字标签与键盘左右/Home/End导航。数据源常驻顶部；光照与背景折叠在Display，玻璃和裁剪盒位于Crop，几何和计时只在Info显示。隐藏页签保持挂载，切换不改变渲染参数。裁切已启用时Crop页签显示状态点。

点击预设旁的 `Edit transfer function` 曲线图标打开视口下方的编辑区，默认收起。桌面以宽图表配右侧属性，窄屏改为纵向并在编辑区内滚动；均不覆盖三维画面。画布根据剩余空间重新渲染，开关区域不重置相机、曲线或裁切。图表坐标随实际宽度调整，控制点命中不依赖固定侧栏尺寸。关闭按钮或编辑区非输入控件上的Escape收起区域并返回入口焦点，数值/下拉框的Escape不关闭整个区域。

- 图表横轴为窗宽窗位对应的 HU 范围，纵轴为参考物理长度 1 mm 的不透明度百分比。整体 `Opacity scale` 仍作为独立倍率参与渲染。
- 背景灰色柱状图是完整原始体的强度分布，纵向使用对数计数并归一化。它不随裁剪盒或玻璃切平面重新统计，也不表示组织分类。
- 点击控制点选择，拖动改变强度位置与不透明度。端点横向位置锁定，但可调整颜色及透明度；内部点不能跨越相邻点。
- 颜色选择器、HU 输入和透明度输入提供精确编辑。方向键移动控制点，Shift 增大步幅；内部点可用 Delete 删除。
- 加号在选中点附近区间插入插值控制点；双击图表可按横向位置插点。最多 64 点，最少保留两个端点。插点时插值当前颜色和透明度，不凭空指定新的外观。
- `Opacity range` 默认自动选择纵轴范围，也可固定为 5%、10%、25%、50% 或 100%。拖动期间固定比例，结束后自动范围可重新取景。
- 顶部颜色条与图下颜色渐变跟随当前控制点，`Edited` 标明曲线偏离当前内置或本地保存版本。
- 图表旁 `Restore built-in curve` 只恢复当前基础内置预设的控制点，保留 WW/WL、整体透明度、光照、背景、相机及裁切。预设选择框旁 `Reset preset` 则恢复当前选中预设的整套显示参数。

拖动仍走原有 34 ms 预览节流和停止后的精细帧流程；图表显示当前编辑草稿，图像在渲染完成后更新。不是每次指针事件都承诺完成一张 GPU 图像。

## 2. HU 与窗口的关系

控制点内部位置 $u$ 仍在 $[0,1]$，窗口映射为：

$$
HU = WL + (u-0.5)\,WW
$$

因此修改 WW/WL 会改变控制点对应的 HU，不将曲线固定到另一套绝对 HU 坐标。编辑器和现有 CUDA 积分使用同一映射，避免引入第二套窗宽窗位语义。窗外采样仍按原实现 clamp 到两端。

颜色与 alpha 在相邻控制点间线性插值；后端用原有 256 项查找表。alpha 是参考长度上的不透明度，不是整条视线最终像素的不透明度。渲染时继续根据实际采样长度校正，不修改 HU 或原始 DICOM。

## 3. 直方图

后端在场景加载的 GPU worker 中，对解码后的完整强度体统计一次最小值、最大值与 256 个等宽分桶；最大值计入最后一桶，常量体计入第一桶。分桶计数之和等于 `voxelCount`。统计采用两遍 CPU 扫描，耗时计入加载的 `dataLoadMs`，不是 GPU 上传耗时。

返回的 `histogram` 仅含 `minimum`、`maximum`、`counts`、`voxelCount`，不传原始体素、患者标签或文件名。图表显示当前窗口内的桶，桶宽有限，不把该图当作精确 HU 定量工具。体外值及加载器规范化过的 padding 会参与当前体的分布统计。

## 4. 本地自定义预设

点击保存图标后才展开名称输入，确认保存创建本地副本，随后可在 `Local presets` 中选择。最多保存 32 项，名称最长 64 字符。修改已保存版本后再次保存会生成新副本；第一版不原位覆盖已有条目。

预设保存在浏览器当前站点的 `localStorage`，键为 `medgl.transfer-presets.v1`，结构有版本校验。只存名称、基础内置 preset ID、曲线、WW/WL、整体透明度和光照；背景保存为中性默认值且载入时保留当前背景。不会保存序列标识、患者数据、直方图、相机或图像。

刷新和重新打开同一浏览器站点可载入，但不会同步到其他浏览器、端口或机器。清理站点存储会删除本地预设。删除需确认；读写权限、容量或损坏数据出错时显示错误，不影响当前渲染。无法识别的基础内置 preset 不能应用。

切换相机、裁剪、玻璃平面和断线重连保留当前曲线；切换 preset 载入对应版本，加载新序列恢复初始显示。内置预设始终由后端定义，本地副本不提交给服务器持久化。

## 5. 兼容与验证

预设目录和 initial style 新增可选 `transferFunction`，ready 声明 `transferFunctionSupported=true`。render 的 `style.transferFunction` 复用原有后端校验，实际图像元信息返回控制点快照。协议版本仍为 1。旧目录或旧帧缺少字段仍可解析；服务未声明能力时禁用编辑和本地预设应用，不发送曲线覆盖。
